# ตลาดหอ (Dorm Market)

เว็บตลาดซื้อ-ขายของมือสองสำหรับนักศึกษาที่อยู่หอพัก
โครงงานปลายภาค วิชา Artificial Intelligence in Modern Life (040603005)

## ปัญหาที่แก้
ตอนย้ายเข้า/ออกหอ ของที่ไม่ใช้แล้ว (พัดลม ชีท ชั้นวางของ) ขายยาก ต้องโพสต์ตามกลุ่มแชต
ของหาย ไม่รู้ตั้งราคาเท่าไร และไม่รู้ว่าผู้ขายอยู่อาคารไหน ชั้นไหน

## ฟีเจอร์
- ลงขายด้วยรูปเดียว AI ช่วยเขียนชื่อ คำอธิบาย แนะนำหมวดหมู่ สภาพ และช่วงราคา (แก้ไขได้ก่อนลงขาย)
- ค้นหาตามคำ กรองตามอาคาร ชั้น และหมวดหมู่
- แสดงช่องทางติดต่อผู้ขาย เพื่อนัดรับของในหอ
- ผู้ขายเปลี่ยนสถานะ ว่าง / จองแล้ว / ขายแล้ว และลบประกาศได้
- รองรับโหมดมืดและหน้าจอมือถือ

## วิธีใช้งาน
เปิดหน้าเว็บ กด "ลงขายของ" เลือกรูป ใส่ Anthropic API key ของตัวเองในช่อง AI แล้วกด "ให้ AI ช่วยเขียน"
ถ้าไม่ใส่ key ก็กรอกข้อมูลเองได้ ฟีเจอร์อื่นใช้งานได้ตามปกติ

- API key เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น และถูกส่งไปที่ api.anthropic.com เท่านั้น
- ข้อมูลประกาศเก็บในเบราว์เซอร์ของแต่ละเครื่อง ยังไม่แชร์ข้ามเครื่อง (ดูหัวข้อพัฒนาต่อ)

## เทคโนโลยี
HTML + CSS + JavaScript ไฟล์เดียว (`index.html`) ไม่ต้อง build
AI: Claude API (vision) เรียกจากเบราว์เซอร์โดยตรง

## วิธีเผยแพร่บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลด `index.html` กับ `README.md`
2. ไปที่ Settings > Pages > Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 นาที ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## การใช้ AI ในการสร้างงานนี้
- ใช้ Claude วางแผนไอเดีย เลือกขอบเขตให้ทำเสร็จทันเวลา และเขียนโค้ดหน้าเว็บ
- ใช้ AI ในตัวแอป: อ่านรูปสินค้า สร้างประกาศ แนะนำราคา
- (เพิ่มรายการ Prompt หลักที่ใช้จริงของกลุ่มตรงนี้)
